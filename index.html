Case 库

收集运行中人工标注的 goodcase：一条 query + 某版本/模型的输出 + 评语，用于沉淀正例、回溯参考。
（与「评测集库」区分：Case 库存的是实际跑出来的好样本，评测集库存的是成套评测 query。）（mock）

评测集库

按主题组织的 query 集合，用于让不同模型跑同一批题、横向对比质量与指标。
（在 模型评测 模式下选一个评测集，A/B 两个模型各跑一遍。）（mock）

评测集主题题量示例 query用途

怎么用：去 模型评测 模式，在「评测集」下拉里选一个，A/B 两个模型跑同一批 query，逐条对比。
